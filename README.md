# MachineMemory
A Breakdown response agent with hindsight memory-Microsoft3.0 hackathon

A breakdown-response agent that remembers every past failure and gets smarter with each fix.
Built for Microsoft 3.0 Hackathon.

## Problem
Maintenance knowledge lives in technicians' heads. When they leave or are off shift, 
that knowledge disappears — teams re-diagnose the same failures from scratch.

## Solution
A chat assistant that stores every breakdown (machine, symptom, root cause, fix, downtime)
and recalls similar past cases to give specific, proven fixes instead of generic advice.

## How it works
1. Technician reports a symptom
2. Agent recalls similar past breakdowns
3. Agent suggests a likely cause and proven fix
4. Technician confirms if it worked
5. Outcome is retained for next time

## Tech Stack
- Frontend: Streamlit
- LLM: Groq (gpt-oss-120b)
- Memory: Hindsight memory (retain + recall)
